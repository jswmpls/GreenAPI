# Telegram-чат на GREEN-API

Минимальный чат для отправки и получения текстовых сообщений в Telegram через [GREEN-API](https://green-api.com/telegram). React + TypeScript + Vite.

## Подготовка (один раз)

1. В [консоли GREEN-API](https://console.green-api.com) создайте инстанс Telegram (тариф Developer).
2. Авторизуйте его: Telegram → Настройки → Устройства → Подключить устройство → QR из консоли.
3. Включите уведомления: «Изменить» на панели инстанса → включить входящие и исходящие → поле URL вебхука **оставить пустым** → «Сохранить». Настройки применяются до 5 минут.
4. Скопируйте `idInstance`, `apiTokenInstance` и `apiUrl` со страницы инстанса.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно <http://127.0.0.1:5173/>). Терминал не закрывайте.

## Использование

1. Введите `idInstance`, `apiTokenInstance` и свой `apiUrl` (например, `https://4100.api.green-api.com`).
2. Введите номер получателя без плюса (`79876543210`) и нажмите `+`.
3. Напишите сообщение и отправьте. Ответ получателя появится в чате.

## Если не открывается (`ERR_CONNECTION_REFUSED`)

- Проверьте, что `npm run dev` запущен, и откройте именно тот адрес, что в терминале.
- На Windows попробуйте `127.0.0.1` вместо `localhost` или добавьте в `vite.config.ts`: `server: { host: '127.0.0.1', port: 5173 }`.

## Сборка
